# Code of Conduct

## Our standard

We want Mathnotes to be a welcoming project for contributors of every background and experience level. Be respectful, assume good intent, give actionable feedback, and focus criticism on the work rather than the person.

Harassment, discrimination, threats, deliberate intimidation, sexualized attention, doxxing, and sustained disruption are not acceptable in project spaces.

## Scope and enforcement

This standard applies to repository discussions, issues, pull requests, reviews, and other spaces where someone represents the project.

Report conduct concerns privately through the maintainer's GitHub profile contact method. Reports will be reviewed confidentially and addressed proportionately, including warnings, temporary restrictions, or removal from project spaces when necessary.
